# Quiz Images

This folder is reserved for original, page-related quiz images used by Quiz Challenge Bangladesh.

## Recommended structure

- images/bangladesh/
- images/computer-ict/
- images/english-grammar/
- images/vocabulary/
- images/general-knowledge/

## File naming

Use descriptive, stable names such as:

- computer-ict-quiz-0014-cpu.jpg
- bangladesh-quiz-0014.jpg
- english-grammar-quiz-0005.jpg
- vocabulary-quiz-0010.jpg

## Website image URL

After an image is uploaded to this repository, the preferred public URL is:

https://quizchallengebd.com/images/<path-to-image>

Example:

https://quizchallengebd.com/images/computer-ict/computer-ict-quiz-0014-cpu.jpg

The same public URL can be used when a direct image URL is needed for Facebook or other posts.

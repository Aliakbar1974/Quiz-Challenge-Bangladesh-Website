40-CHAPTER LEARNING ROADMAP

English Grammar: Learn the Rules, Understand the Examples

A step-by-step grammar library for school learners, cadet college admission candidates, BCS and other competitive-exam candidates. Learn a rule, study examples, practise it, and then test your understanding.

How to study with this library

  1. Read the lesson and note the rule in your own words.
  2. Compare the correct examples with the common mistakes.
  3. Complete the practice tasks before checking the answers.
  4. Use the linked quiz to test recall, then revisit the rule behind each mistake.

Learning principle: memorising an answer is not the same as understanding a rule. Each chapter is intended to explain the pattern and show how to apply it in a new sentence.

The chapters are being developed and reviewed progressively. The roadmap below shows the planned sequence; a chapter is marked available only when its lesson page has been published.
